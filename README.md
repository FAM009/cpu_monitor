# cpu_monitor
Console app for showing CPU loading per each core

Has optional parameters 
to save CPU loading info in file

# Usage: ./cpu_monitor <log_interval_seconds> <file_path>

Example: 

./cpu_monitor 5 cpu_log.txt


Commands:
  [Press ENTER or type 'p']: Print CPU load to stdout
  [Type 'q' + ENTER]: Exit program
